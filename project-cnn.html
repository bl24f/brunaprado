Project Overview

Designed and delivered a comprehensive 40-minute technical lecture on CNN architecture to a senior-level graduate class with a math-literate professor. The goal was to make complex deep learning concepts approachable without oversimplifying — covering the math behind convolutions, backpropagation through CNNs, and real-world applications in medical imaging and computer vision.

Key Contributions
  • Covered convolution math, feature maps, pooling layers, and activation functions from first principles
  • Explained backpropagation through CNN layers including gradient flow and weight updates
  • Discussed major architecture patterns: LeNet, VGG, ResNet, and their key innovations
  • Built custom SVG diagrams, animated GIFs, and an interactive HTML explainer for visual learners
  • Highlighted medical imaging and computer vision applications relevant to AI/ML engineering
